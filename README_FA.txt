نُوا — پروژه آماده ساخت APK روی گوشی اندرویدی

این بسته پروژه اندروید است که فایل HTML نُوا را داخل برنامه قرار می‌دهد؛ فایل HTML جداگانه لازم نیست.
در این محیط APK نهایی کامپایل نشده، چون Android SDK/Gradle برای ساخت و امضای APK در دسترس نبود.

روش پیشنهادی با خود گوشی:
1) فایل ZIP را از حالت فشرده خارج کن.
2) برنامه AndroidIDE را نصب و باز کن (از منبع رسمی آن).
3) در AndroidIDE گزینه Open Project را بزن و پوشه NOVA_Android_APK_Project را انتخاب کن.
4) اجازه بده Gradle Sync کامل شود؛ اینترنت برای دریافت ابزارهای ساخت لازم است.
5) از منوی Build، گزینه Build APK(s) را اجرا کن.
6) APK معمولاً در app/build/outputs/apk/debug/app-debug.apk ساخته می‌شود.
7) APK را نصب کن؛ اگر اندروید اجازه خواست، نصب از این منبع را فعال کن.

نکته‌ها:
- برنامه از WebView داخلی اندروید برای نمایش رابط HTML استفاده می‌کند.
- مجوز اینترنت فقط برای قابلیت جست‌وجوی اینترنتی موجود در نسخه HTML است؛ بدون اینترنت رابط محلی باز می‌شود.
- قابلیت‌های وابسته به مرورگر/نسخه WebView ممکن است با مرورگر گوشی کمی تفاوت داشته باشند.
- این پروژه با Java و Gradle ساخته شده و نیاز به سرویس یا حساب کاربری ندارد.
